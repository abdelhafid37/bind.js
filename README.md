# bind.js

> A lightweight JavaScript library for expressive DOM manipulation and fluent APIs.

<p align="center">
  <img src="./assets/cat-computer.gif" width="300" alt="Cat typing on a keyboard">
</p>

bind.js is a tiny, dependency-free JavaScript library that makes working with the DOM simpler and more enjoyable.

**Currently under active development.**

## Vision

Build a lightweight, chainable JavaScript library with a simple and clean API.

A future version will include an optional Darija API to help Moroccan beginners learn JavaScript while keeping the standard English API.
